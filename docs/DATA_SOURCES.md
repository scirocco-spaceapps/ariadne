# Data sources

Append-only. Every value shown to a user, or used to compute one, has a row here. Add rows at the
end; never rewrite or delete an existing row. To correct a row, append a new row that says which
row it supersedes.

Provenance is one of: **Observed** (measured by an instrument), **Derived** (computed from Observed
data by a deterministic method), **Modeled** (output of our or a published model), **Assumed**
(chosen by us without a source), **Simulation** (produced by the EVA simulation).
