# Notes for owners

One file per person: `nuri.md`, `mazlum.md`, `alikoray.md`, `bunyamin.md`, `furkan.md`,
`yusuf.md`. Create a file when you need it.

- **Leave a note** when your task needs a change in someone else's directory. Append a dated
  section at the end of their file: what must change, where, why, and which task needs it. Link
  your PR if there is one. Do not make the change yourself.
- **Read your file** at the start of every task. Root `CLAUDE.md` tells every Claude session to do
  this.
- **Close a note** by deleting it from your own file in the PR that does the work. Only the file's
  owner deletes lines; everyone else only appends.
