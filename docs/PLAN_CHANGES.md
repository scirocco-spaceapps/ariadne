# Changes from the plan documents

The team works from three documents outside the repo: the **Görev Kitabı** (task book, 49 cards
and prompts), the **Oyun Planı** (game plan) and the **Görsel Brif** (visual brief). The repo
moved on from them during Y0 and Y1. This file lists every difference, per task card.

**Precedence:** `contracts/` (tag `contracts-v1`) > this file > the task-book prompt > the game
plan > the visual brief. When a prompt you paste says something different from this file, follow
this file and mention it in your PR.

Owner: Yusuf. Why each change was made: `docs/DECISIONS.md` (dated lines).

## For everyone

- **Repo:** `https://github.com/scirocco-spaceapps/ariadne` (organization). The old
  `ozyusuf/ariadne` URL redirects; update an old clone with
  `git remote set-url origin https://github.com/scirocco-spaceapps/ariadne.git`.
- **Contracts are frozen** at tag `contracts-v1`. Changes go to Yusuf as a PR on a `contracts/...`
  branch. The Y1 decisions were made by Yusuf with Claude because the team asked for defaults.
- **Fixtures live in `contracts/fixtures/assets/`**, not `fixtures/rasters/`. The fixture AOI is a
  SYNTHETIC 500 x 400 m area with the same keys and pixel sizes as the real 2500 x 2000 m AOI.
  It now also has SYNTHETIC `track.geojson`, `waypoints.geojson`, `targets.geojson` and
  `slope_2m.f32`. Regenerate with `python contracts/tools/make_fixtures.py`; check with
  `python contracts/check.py`.
- **GeoJSON is in AOI metres `[x, y]`, not lon/lat.** Every GeoJSON file is a FeatureCollection
  with top-level `provenance` and `source`. Schemas: `TrackCollection`, `WaypointCollection`,
  `TargetCollection`, `GeologyCollection` in `contracts/openapi.yaml`.
- **Asset paths:** `assets_base` is `bright-angel/` (relative). Web loads
  `VITE_ASSETS_URL + assets_base + file`; planner and pipeline read `DATA_DIR + assets_base + file`
  (`DATA_DIR=/srv/assets` on the server). Hostnames are not in the contract.
- **Ports:** planner 8000, mission-control 8080, web 5173 (as in N2).
- **Every `.f32` raster ships a sidecar** `<file>.json` with at least
  `{width, height, px_m, min, max}`. Extra fields are allowed.
- **No `/envelope` endpoint.** The visual brief mentions one; the envelope is computed in the web
  app from `cost_to_home_2m.f32` (Y5).
- **Ideas:** append `- LATER: <what> — <why> — <hours> — <name>` to `docs/DECISIONS.md` and go back
  to your card.
- **`/pr-ac` works with multi-folder cards.** It allows exactly the paths in your card's
  "Work only inside:" line plus your `docs/ai-use/<name>.md`. Branch name = the first folder of
  that line, e.g. `content/b2-sites`.
- **AI-use files:** `docs/ai-use/` + `yusuf.md`, `nuri.md`, `mazlum.md`, `alikoray.md`,
  `bunyamin.md`, `furkan.md`.

## Mazlum — `mission-control/`

- **M1:** send one `state` right after `hello`, then every 500 ms while running (2 Hz), plus one
  immediately after every control, event or script call. Close codes: `4404` unknown session,
  `4400` bad role.
- **M2:** `seek` must have `t_min` (schema enforces it). Default `speed` is 6 simulated minutes per
  real second. `visited` = stops whose full dwell finished.
- **M3:** on `storm_alert`: end any dwell, set `alert` and `abort_path` (planner `/abort`, else the
  body's `abort_path`), walk it with `leg = null` and `at_stop = null`, send `arrived` at the safe
  haven and set `running = false`. A dwell cut short is not visited. On `clear`: `alert` and
  `abort_path` become null and, if not home yet, the plan resumes toward the next unvisited stop.
  `lead_min` is fixed at the moment the alert is raised.
- **M4:** every part carries `provenance`, `source`, `mode`; `space_weather` also needs
  `fetched_at` and `stale`. Weather from `meda.json` → `{sol, values, units, mode: "archive"}`;
  radiation from `model/params.json` `radiation_dose_rate` → `{value, unit, measured_at}`,
  provenance Modeled.
- **M5:** `POST /sessions/{id}/script {name: "demo90"}` is already in the contract (Ack; 400 for an
  unknown name; 404 for an unknown session).
- **M6:** partner is `{agency, mission, value, unit, source_url}` **plus** the common
  `provenance`, `source`, `mode` (optional `description`, `fetched_at`).
- **Note:** the Go module path is still `github.com/ozyusuf/ariadne/mission-control`. It works;
  rename it only if you want to.
