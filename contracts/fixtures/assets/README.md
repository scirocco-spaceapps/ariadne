# SYNTHETIC assets — not real data

Every file in this folder is generated by `contracts/tools/make_fixtures.py` for development and
tests. Nothing here comes from a NASA product. Never show these to users as real.

Fixture AOI: 500 x 400 m (`../aoi.json`), same keys and pixel sizes as `contracts/aoi.json`.

| File | Size (px) | Content |
|---|---|---|
| `ortho_50cm.jpg` | 1000 x 800 | RGB gradient (red east, green north), "SYNTHETIC" burned in |
| `ortho_1m.jpg` | 500 x 400 | same |
| `hillshade_2m.png` | 250 x 200 | grey hillshade of the DEM, sun az 315°, alt 45° |
| `dem_4m.f32` | 125 x 100 | tilted plane + one 30 m hill at (400, 100); formula, min and max in sidecar `.json` |
| `slope_2m.png` | 250 x 200 | RGB, coloured by the `slope.legend` bins |
| `traversability_2m.png` | 250 x 200 | RGB, coloured by the `traversability.legend` classes; fixture thresholds go < 15° ≤ caution < 25° ≤ no-go (Assumed) |
| `cost_to_home_2m.f32` | 250 x 200 | straight-line distance to the safe haven / 50 m·min⁻¹, minutes |
| `cost_2m.f32` | 250 x 200 | planner input, outside the contract: 1/50 min·m⁻¹ everywhere, NaN (impassable) where the DEM slope ≥ 25° |
| `slope_2m.f32` | 250 x 200 | slope of the DEM in degrees (optional `slope_values` entry) |
| `track.geojson` | 7 segments | SYNTHETIC rover traverse, sols 1200–1206, AOI metres |
| `waypoints.geojson` | 7 points | SYNTHETIC rover stops with sol, site, drive |
| `targets.geojson` | 1 point | SYNTHETIC target `t1`, matches the target in `../stops.json` |

Optional `cost_to_home_flat`, `seen_not_touched`, `dem_geotiff` and `geology` are deliberately
absent so clients exercise the missing-optional path.

GeoJSON coordinates are AOI metres `[x, y]`, not lon/lat (see `openapi.yaml`, files: vectors).

`.f32`: little-endian float32, row-major, row 0 = north edge, no header. Pixel centre of
(row, col): `x = (col + 0.5) * px_m`, `y = 400 - (row + 0.5) * px_m`.
